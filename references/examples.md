# 키크니 작명 코퍼스 81건

출처: 키크니 작가 작명 캡처 81장. 의뢰문은 요지, 답은 "X 는 어떨까요"의 X.

**81건 전부가 같은 일을 한다 — 이미 세상에 있는 표현 하나를 가져와 의뢰 상황으로 다시 읽는다.**
두 단어를 붙여 없던 말을 만든 사례는 **0건**이다.

원표현이 얼마나 변형됐는지로 세 등급으로 나뉜다. 등급이 낮을수록(변형이 적을수록) 강하다.

## 코퍼스가 말하는 것

- **81건 중 두 단어를 합성해 없던 말을 만든 것: 0건.** 전부 이미 있는 표현이다.
- A등급(소리 무변형) 28건이 가장 많다. **안 바꾸는 게 최고**라는 뜻이다.
- 바뀐 음절은 거의 전부 **이웃한 소리**다 (티/띠, 로/노, 코/꼬, 두/듀, 연/년, 개/깨). 완전히 다른 음절로 갈아끼운 사례가 없다.
- 답은 **항상 하나**, 풀이 없음. 예외는 #75 아말감(축약이라 풀이가 앞에 붙음)과 #40 김나밥이(설명 한 줄).
- 이모지를 쓴 사례 1건(#40 김나🔥밥이), 구두점으로 끊은 사례 여러 건(#35 진도,깨 / #50 명동 칼,궁수 / #12 산,부인과 / #28 페이,커 / #64 할아.범 / #65 싸,입이).
