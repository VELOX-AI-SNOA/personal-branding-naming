`SKILL.md`의 작업 순서를 실제로 돌릴 때 보는 상세. 예시 번호는 `examples.md`의 #.

## 0. 조준점 — 무엇을 때릴 것인가

이름을 찾기 전에 **이 의뢰에서 웃긴 지점 하나**를 한 문장으로 적는다. 특징 요약이 아니다.

| 의뢰 | 조준점 (웃긴 지점) | 답 |
|---|---|---|
| 무다리라 놀리는데 남편은 턱이 나옴 | 놀리는 사람이 정작 튀어나온 게 있다 | 과속방지턱 |
| 70인데 성질이 안 죽음 | 노인인데 인내가 없다 | NO인내 |
| 차은우 아닌 차씨 남편 | 같은 성인데 급이 다르다 | 차선책 |
| 곤듀님이라 저장했는데 아저씨 됨 | 공주에서 아저씨로 추락했다 | 곤듀박질 |
| 겁 많은 강아지를 달래는 미용사 | 모질게 못 하는 사람이다 | 모질지 못해 |
| 고기 안 익었는데 먹는 남친 | 못 참는다 | 노익힘 |

**조준점이 하나면 이름도 하나를 때린다.** 특징을 골고루 담으려 하면 요약이 되고, 요약은 안 웃긴다.
의뢰문이 밋밋해 웃긴 지점이 안 보이면, 그 사람에게서 **가장 어긋난 것**(직업과 취미의 충돌, 말과 행동의 불일치,
잘하는 것과 못하는 것의 낙차)을 찾는다.

## 0-2. 거리 — 의뢰 분야에서 멀수록 놀랍다

같은 분야 용어를 찾으면 **당연해진다.** 놀라움은 소리는 같은데 세계가 완전히 다를 때 온다.

| 의뢰 세계 | 숙주가 온 세계 | 답 |
|---|---|---|
| 처형(가족) | 형벌 | 공개처형 |
| 노산(임신) | 생화학 | 아미노산 |
| 제모(미용) | 배우 이름 | 안재모 |
| 등산·부인(취미) | 의학 | 산,부인과 |
| 전역 대위(군대) | 가구 | 침대위 |
| 위염(신체) | 비만 치료제 | 위 고비 |
| 보수적 트레이너 | 역사 + 해부학 | 흥선대흉근 |
| 치과(의료) | 축구선수 | 이강인 치과 |

**약한 예 (같은 세계라 당연함)**: 직업상담사→직업정신 · 하역→적재적소 · 잡화점→만물박사 ·
부동산 컨설턴트→마감재 · 일식 조리사→물 만난 고기. 전부 맞는 말이지만 "어떻게 저걸 떠올렸지"가 없다.

찾을 때 이렇게 묻는다: **"이 소리가 들어간 말 중에, 이 사람 일과 아무 상관 없는 세계의 말은 뭐가 있지?"**

## 0-3. 낙차 — 센 말일수록 크게 뒤집힌다

원표현이 **세거나·전문적이거나·유명할수록** 뒤집힘의 낙차가 크다.

| 낙차 큼 (좋음) | 낙차 작음 (밋밋함) |
|---|---|
| 형벌·범죄·질병·욕설·군사·법률: 공개처형, 무장강도, 정신병자, 귀싸대기, 사이비, 민간인 사찰 | 원래 좋은 뜻의 순한 말: 만물박사, 직업정신, 적재적소, 물 만난 고기 |
| 전문 학술어: 아미노산, 아말감, 알레르기, 당뇨 전단계 | 업종 간판에 흔한 말: 당충전, 쉼표, 손맛 |
| 유명인 이름: 안재모, 로이킴, 이강인, 흥선대원군 | 누구나 쓰는 덕담: 대박, 행복, 미소 |
| 강한 관용구: 곤두박질, 어쩔 수가 없다, 인생 족같다 | |

순한 말은 뒤집어도 제자리다. **센 말이 순한 상황으로 떨어질 때** 웃음이 난다.

## 1. 이 작업은 조합이 아니라 검색이다

**만드는 게 아니라 찾는 것이다.** 머릿속 어휘 저장고에서 "의뢰 상황으로도 읽히는 기존 표현"을 찾아낸다.
없으면 계속 찾는다. 없다고 두 단어를 붙여 만들면 그 순간 실패다.

```
✗ 만들기:  리어카 + 마카롱 = 리어카롱
           파스 + 배드민턴 = 파스민턴
           짐 + 산타클로스 = 짐타클로스
           파도 + 도서관 = 파도서관

○ 찾기:    "처형"이 들어간 기존 표현이 뭐가 있지? → 공개처형 (#1)
           "장"과 "물"이 같이 있는 말은? → 장마 (#2)
           "턱"이 들어간 흔한 말은? → 과속방지턱 (#3)
           제모 안 하는 사람들… "안 제모"로 들리는 말은? → 안재모 (#14)
```

두 방식의 결과를 소리 내어 읽어 보면 차이가 즉시 난다. 만든 것은 처음 듣는 말이라 아무 반응이 없고,
찾은 것은 **아는 말인데 뜻이 뒤집혀서** "아!" 소리가 난다.

## 2. 찾는 절차

### 0단계 — 조준점을 먼저 적고, 거기서 소리 재료를 뽑는다

§0에서 잡은 조준점 한 문장을 적고, 그 문장에서 이름·성씨·나이·지명·특징어·의뢰자가 쓴 구절을 뽑는다.

```
"처형이 요리 유튜브" → 처형 / 요리 / 유튜브
"사주에 물 부족한 장씨" → 장 / 물
"턱이 나온 남편" → 턱
"겨드랑이 털 안 나는" → 안 제모 / 겨드랑이
```

### 1단계 — 그 소리가 통째로 들어간 기존 표현을 **의뢰 분야 밖에서** 찾는다 (A등급 사냥)

**소리를 하나도 안 바꾸고** 그 재료를 품은 말이 이미 있는지 본다. 같은 분야 용어가 먼저 떠오르면 일단 적어 두고, **다른 세계에도 같은 소리가 있는지 한 번 더** 훑는다 — 형벌·범죄·질병·군사·법률·의학·역사·연예인·스포츠·요리.

| 재료 | 이미 있는 표현 | 결과 |
|---|---|---|
| 처형 | 공개처형 | #1 |
| 장 + 물 | 장마 | #2 |
| 턱 | 과속방지턱 · 턱걸이 · 주걱턱 | #3 |
| 차(성씨) | 차선책 · 차차기 · 차포 | #4 |
| 미리 | 미리보기 · 미리미리 | #5 |
| 법 | 맞춤법 · 헌법 · 법대로 | #6 |
| 아미 + 노산 | 아미노산 | #7 |
| 산책 | 산책 = 산(買) 책 | #8 |
| 위 | 위고비 · 위장 · 위아래 | #9 |
| 어린 | 광기 어린 · 어린이 · 철없는 | #10 |
| 대위 | 침대위 | #11 |
| 산 + 부인 | 산부인과 | #12 |
| 상의 | 상의없이 · 상의탈의 | #13 |

**이 단계에서 나오면 다른 단계를 볼 필요가 없다.** 코퍼스 81건 중 28건이 여기서 끝난다.

### 2단계 — 한 음절만 이웃한 소리로 바꿔 본다 (B등급 사냥)

1단계에서 안 나오면, 재료와 **소리가 한 끗 차이인** 기존 표현을 찾는다.

```
말띠 → 말티즈가 있다 → 말띠즈 (티→띠)          #29
노처녀 → 로맨티스트가 있다 → 노맨티스트 (로→노)   #30
꼬매다 → 코미디언이 있다 → 꼬매디언 (코→꼬)      #31
```

바꿀 수 있는 것은 **이웃한 소리 한 음절**이다.

| 허용 (원표현이 그대로 들림) | 금지 (원표현이 안 들림) |
|---|---|
| 티↔띠, 로↔노, 코↔꼬, 두↔듀, 연↔년, 개↔깨, 조↔죠, 짜↔자 | 배드→파스, 마→리어카, 산→짐, 도→파도 |

**테스트: 바꾼 이름을 소리 내어 읽었을 때 원표현이 들리는가.**
말띠즈 → 말티즈가 들린다 ○ / 파스민턴 → 배드민턴이 안 들린다 ✗

### 3단계 — 끊어 읽는 위치만 바꿔 본다 (C등급 사냥)

소리는 그대로 두고 띄어쓰기·구두점·표기만 바꿔 다른 뜻이 나오는지 본다.

```
노인네 → NO인내      #19
이디야 → 이 뒤야      #20
이국적 → 이 국적이    #21
할아범 → 할아.범      #64
사이비 → 싸,입이      #65
```

### 4단계 — 그래도 없으면 재료를 바꿔서 0단계로 돌아간다

의뢰문의 **다른 단어**로 다시 돈다. 재료를 다 써도 안 나오면 유의어로 넓히되,
그 유의어를 들었을 때 의뢰 상황이 떠오르는 것만 쓴다(백점→공부 ○, 조각→디저트 ✗).

**절대 하지 않는 것: 안 나온다고 두 단어를 붙여 만들기.**

## 3. 어휘 저장고 — 어디서 찾나

검색할 목록이다. 의뢰 재료를 들고 아래를 훑는다.

낙차가 큰 저장고를 **먼저** 훑는다.

| 저장고 | 코퍼스 예 |
|---|---|
| **형벌·범죄·질병·군사·법률** (낙차 최상) | 공개처형, 무장강도, 민간인 사찰, 정신병자, 사이비, 알레르기, 당뇨 전단계, 과속방지턱 |
| 관용구·속담·일상 표현 | 어쩔 수가 없다, 마지못해, 손에 꼽히게, 상의 없이, 인생 족같다, 놀고있네, 곤두박질 |
| 전문·행정 용어 | 공개처형, 과속방지턱, 차선책, 맞춤법, 아미노산, 산부인과, 아말감, 당뇨 전단계, 쉬었음 청년, 민간인 사찰 |
| 사람 이름 (배우·가수·선수·정치인·역사인물) | 안재모, 로이킴, 이강인, 흥선대원군, 도널드 트럼프, 나이팅게일, 슈퍼주니어, 김나박이 |
| 브랜드·상품·작품 | 말티즈, 캐치 티니핑, 이디야, 나무위키, 네이버스토어, 이웃집 토토로, 위고비, 밀리의 서재, 두바이 쫀득 쿠키 |
| 지명 | 명동 칼국수, 치앙마이, 히말라야, 킬리만자로, 나고야, 송내역 |
| 밈·유행어·속어 | 사이비, 미친새끼, 바바리맨, 정신병자, 테토남, 갸루 |
| 노래·영화·프로그램 제목 | 복수는 나의 것, 나의 해방일지, 전국노래자랑, 너에게 닿기를 |

**저장고에 없는 말은 쓰지 않는다.** 내가 방금 만든 조어는 저장고에 없다.

## 4. 톤

- 의뢰문에 불평·자조가 있으면 그 수위를 따른다 (#71 "동생 새끼"→밑인새끼, #36 처먹언니, #34 년년생).
- 의뢰문이 애정·축하·포부면 디스하지 않는다 (#55 102세 할머니, #51 무인 꽃집).
- 의뢰자가 톤을 지정하면(친근하게·젊게·전문적으로) 그에 맞춘다 (#46 연포티, #64 할아.범).
- 고객이 보는 이름(상호·계정·모임명)에는 학벌·지역·외모·성별·정치·종교·질병·죽음처럼
  통념상 반감을 부르는 말을 넣지 않는다. 사적 별명의 디스는 예외다.

## 5. 검증 — 여섯 개 다 통과해야 본안

1. **이미 있는 말인가.** 이름을 소리 내어 읽으면 아는 표현이 들리는가. 처음 듣는 조어면 탈락.
   리어카롱·파스민턴·짐타클로스·파도서관은 여기서 전부 탈락한다.
2. **뜻이 뒤집혔는가.** 원래 뜻과 의뢰 상황, 두 가지로 동시에 읽히는가. 한 가지로만 읽히면 그냥 인용이다.
2-1. **먼 데서 왔는가.** 원표현이 의뢰 분야 밖의 말인가 (§0-2). 같은 분야면 당연해서 탈락.
2-2. **낙차가 있는가.** 원표현이 세거나·전문적이거나·유명한가 (§0-3). 순한 말이면 밋밋하다.
3. **변형이 최소인가.** 안 바꾼 게 최고(A등급), 바꿔도 이웃한 소리 한 음절(B등급). 두 음절 이상 바뀌었으면 다시 찾는다.
4. **부를 수 있는가.** 그 용도로 사람들이 실제 쓰는 꼴인가. 반려동물·별명은 2~5음절, 상호는 간판에 걸리는가,
   계정명은 띄어쓰기 없이 읽히는가. 상호인데 이름만으로 업종이 안 보이면 풀이 끝에 `간판 표기: OO 디자인공방` 한 구절.
5. **의뢰자가 아는 말인가.** 의뢰자와 그 이름을 부를 사람들이 원표현을 아는가. 53세 조리사에게 품종명,
   77세에게 예능 밈은 안 통한다. 의뢰자가 청중을 지정하면(손주가 좋아할·직원들끼리 부를) 청중 어휘가 우선이고,
   부부·모임 이름은 지정이 없어도 함께 쓰는 사람 전부가 청중이다.

## 6. 약한 이름의 신호 — 보이면 버리고 다시 찾는다

| 신호 | 왜 약한가 | 예 |
|---|---|---|
| **두 단어 합성** | 이미 있는 말이 아니다. 원표현이 안 들린다 | 리어카롱, 파스민턴, 짐타클로스, 파도서관 |
| 두 음절 이상 교체 | 원표현이 안 들린다 | 배드민턴→파스민턴 |
| 특징 단어 나열 | 설명이지 이름이 아니다 | 카톡좀비, 뱃살로그, 고씨감귤원 |
| 비유만 빌림 | 의뢰의 소리가 이름에 없다 | 효자손, 당충전, 조각전 |
| 한 음절 우연 일치 | 겹친 게 단어가 아니라 소리 하나 | 코발트(코) |
| 뜻이 하나로만 읽힘 | 뒤집힘이 없어 웃기지 않다 | 그냥 인용한 사자성어 |
| **같은 분야 용어** | 당연해서 놀랍지 않다 | 직업상담사→직업정신, 하역→적재적소, 잡화점→만물박사 |
| **순한 말** | 뒤집어도 낙차가 없다 | 만물박사, 물 만난 고기, 대박, 행복 |
| 특징을 골고루 담음 | 조준점이 없어 요약이 된다 | 특징 3개를 다 넣은 이름 |
| 의뢰자가 모르는 원표현 | 웃음이 안 터진다 | 53세 조리사에게 먼치킨 |
| 애정 대상에 부정 연상 | 본인이 듣기 싫다 | 오염도산책, 황혼부부, 묘지기 |
