```
말띠즈 는 어떨까요

- 말띠즈 — 말티즈 × 말띠. 포메인데 말티즈로 불러서 한 번 더 웃긴다
- 예비: 포메라니말 — 포메라니안 × 말. 견종은 맞지만 말띠가 약하게 읽힌다

```

## 검증 기록

writing-skills(TDD) 절차로 만들었다. 새 의뢰 3건을 스킬 없이 돌린 기준선에서는 세 건 모두
특징 단어를 붙인 설명형(카톡좀비·뱃살 로그·고씨감귤원)을 6~7개 나열했다. 스킬 적용 후 같은 의뢰 3건:

| 의뢰 | 스킬 없이 (기준선) | 스킬 적용 |
|---|---|---|
| 야근·주말 카톡 팀장 별명 | 카톡좀비 · 주말도둑 · 퇴근차단기 … 7개 + 주의사항 | **톡재자 는 어떨까요** — 독재자 × 톡 |
| 45살 배 나온 김민석 홈트 채널명 | 민석이 뱃살 로그 · 배나온 민석 … 표 7개 + 채널 설명 조언 | **배달의 민석 은 어떨까요** — 배달의 민족 × 민석 (배 달린 민석) |
| 제주 감귤 농장 고씨 부모님 스토어 | 고씨감귤원 · 고귤당 … 6개 + 상표 확인 조언 | **고진감귤 은 어떨까요** — 고진감래 × 감귤 |

세 건 모두 4줄 계약·은/는 조사·숙주 치환·이중독해를 지켰다. 리팩터: 예비안에 실존 인물(배철수)이 숙주로 들어온 건을 보고 용도 조건 한 줄 추가 후 재실행 → **민석 임파서블 은 어떨까요**(미션 임파서블 × 민석), 예비안도 전부 브랜드·작품에서 나옴.
일반화: 새 유형(커피 없인 말 못 하는 30대 여성 직장인 넷 모임명) → **라떼는 말이야 는 어떨까요**(꼰대 밈 재해석). 5회 실행 전부 4줄 계약 유지.
리뷰 반영 후 재실행(팀장 별명) → **야근무휴 는 어떨까요**(연중무휴 × 야근), 예비안(야근야근·카톡노바)도 전부 숙주 있음. 총 6회 통과.

검증 6번(고객 관점·거부감 없음) 추가 후:

| 의뢰 | 규칙 추가 전 (반려) | 규칙 추가 후 |
|---|---|---|
| 공부 잘될 것 같고 꼭 등록해야 할 것 같은 스터디카페 | 카페인서울(인서울=학벌 논쟁), 등록문(등록=사업자 소망) | **청출어라떼 는 어떨까요** — 청출어람 × 라떼. 예비 일등공신·백점다방 |
| 야근·주말 카톡 팀장 별명 (회귀) | — | **톡재자 는 어떨까요** — 사적 별명의 디스 유지. 예비 저녁사자·야근야근 |

업태 규칙(정체성 축 = 실제 업태) 추가 후 스터디카페 재실행 → **책상위권 은 어떨까요**(상위권 × 책상). 예비 일등석·백점백승. 커피 어휘 없음, 이익이 상위권·일등·백점으로 구체화.

동음이의어·즉시 연상 규칙 추가 후 랙돌(파란 눈·코에 점) 재실행 → 반려된 점돌이·코발트·화묘점정 대신 **점끼리 는 어떨까요**(코끼리 × 점 — 코 자리에 점). 예비 파란만점(파란만장 × 점)·점묘(점묘화 재해석). → 이것도 반려(고양이 이름 꼴이 아님).

실제 이름 풀 규칙 추가 후 랙돌 재실행 → **점보 는 어떨까요**(점 + 대형묘), 예비 먼로·깨비. 단 세 이름이 스킬 본문 예시에 있어 깨끗한 검증은 아님. 스킬에 없는 새 의뢰(앞발만 하얀 검은 코숏 수컷, 밥 때만 애교) → **백수 는 어떨까요**(白手 그대로 · 하얀 앞발 + 밥 때만 살가운 집안 백수), 예비 먹튀·먹임자. 실제 이름 꼴(2음절)에 두 특징이 한 단어로 겹침.
